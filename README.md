## Exam-01-Linked-List-Stack
# โจทย์: ระบบจัดการข้อมูลนักศึกษาด้วย Doubly Linked List + Stack (Undo)

สถานการณ์: พัฒนาโปรแกรมจัดการรายชื่อนักศึกษาที่เรียงตาม GPA โดยอัตโนมัติ และรองรับการยกเลิกการกระทำล่าสุด (Undo)

── โครงสร้างข้อมูลที่ต้องใช้ ──
struct Student { char id[10]; char name[50]; float gpa; }
struct DNode { struct Student data; struct DNode *prev; struct DNode *next; }

── ฟังก์ชันที่ต้องเขียน ──
1. insertSorted(head, student) — แทรก node เข้า Doubly Linked List โดยเรียงตาม GPA จากมากไปน้อยอัตโนมัติ และ push operation ลง Stack
2. deleteById(head, id) — ลบ node ที่มี id ตรงกัน และ push operation ลง Stack
3. printForward(head) — แสดงรายชื่อจากต้นไปท้าย: id | name | GPA
4. printBackward(head) — แสดงรายชื่อจากท้ายไปต้น
5. undo(head, stack) — ยกเลิกการกระทำล่าสุด (ถ้า insert ให้ลบออก ถ้า delete ให้ใส่กลับ)

── Stack สำหรับ Undo ──
- ใช้ array หรือ linked list เก็บ operation ล่าสุดไม่เกิน 5 รายการ
- แต่ละ operation เก็บ: ประเภท (INSERT/DELETE) + ข้อมูลนักศึกษา

── เมนูที่ต้องแสดง (วนด้วย do-while) ──
1. เพิ่มนักศึกษา
2. ลบนักศึกษา (ระบุรหัส)
3. แสดงรายชื่อ (ไปข้างหน้า)
4. แสดงรายชื่อ (ย้อนกลับ)
5. Undo การกระทำล่าสุด
0. ออกจากโปรแกรม

── ตัวอย่างผลลัพธ์ที่ต้องแสดงได้ ──
เพิ่ม: 6601 สมชาย GPA=3.80 → เพิ่ม: 6602 สมหญิง GPA=3.50
แสดง Forward: [6601|สมชาย|3.80] → [6602|สมหญิง|3.50] → NULL
Undo: ยกเลิกการเพิ่ม 6602 → แสดง: [6601|สมชาย|3.80] → NULL

── ข้อกำหนด ──
- ใช้ malloc() จอง และ free() คืนหน่วยความจำทุกครั้ง
- มี prototype declaration ทุกฟังก์ชันก่อน main()
- โปรแกรมต้องผ่านชุดทดสอบอัตโนมัติ: เพิ่มข้อมูล 5 คน และ Undo ต่อเนื่อง 2 ครั้ง โดยสถานะหลังแต่ละขั้นต้องถูกต้อง

── รูปแบบสำหรับชุดทดสอบตอนส่งงาน ──
รับข้อมูลผ่าน stdin: เมนู 1 ตามด้วย id, name (ไม่มีช่องว่าง), GPA; เมนู 2 ตามด้วย id; เมนู 3/4 แสดงข้อมูล; เมนู 5 Undo; เมนู 0 ออก
แสดงนักศึกษาแต่ละคนในรูปแบบ id|name|GPA (GPA ทศนิยม 2 ตำแหน่ง) จะมีวงเล็บหรือข้อความเมนูประกอบได้ สามารถแสดงรายการระหว่างเพิ่ม/ลบ/Undo ได้ ระบบตรวจชุดรายการสุดท้ายที่แสดงตามเมนู 3/4
ข้อมูลทดสอบ: 6601 Anan 3.80, 6602 Bua 3.20, 6603 Chai 3.60, 6604 Dao 2.90, 6605 Em 3.40
หลังเพิ่มครบ: 6601,6603,6605,6602,6604; Undo ครั้งแรก: 6601,6603,6602,6604; Undo ครั้งที่สอง: 6601,6603,6602
ทดสอบเพิ่มเติม: เพิ่มครบ 5 คน → ลบ 6602 → Undo คืน 6602 → Undo ยกเลิกการเพิ่ม 6605 → แสดงย้อนกลับ: 6604,6602,6603,6601
คะแนนทดสอบ 10 หน่วย: เพิ่มครบและเรียงถูก 4, Undo ครั้งแรก 2, Undo ครั้งที่สอง 2, คืนข้อมูลหลังลบและแสดงย้อนกลับถูก 2; รวมกับเกณฑ์โครงสร้างแล้วปรับสัดส่วนตามคะแนนเต็มโจทย์


# เกณฑ์การตรวจ
- struct Student มีฟิลด์ id[10], name[50], gpa(float) ครบถ้วน
- struct DNode มีฟิลด์ data(Student), prev, next ถูกต้อง
- insertSorted() แทรกเรียงตาม GPA มากไปน้อยอัตโนมัติและ push operation ลง Stack
- deleteById() ลบ node ตาม id และ push operation ลง Stack ถูกต้องทุกกรณี (head/tail/กลาง)
- printForward() แสดง id|name|GPA จากต้นไปท้าย ถูกต้อง
- printBackward() แสดงจากท้ายไปต้น ถูกต้อง
- Stack เก็บ operation ได้ไม่เกิน 5 รายการ แต่ละ operation มี type (INSERT/DELETE) + ข้อมูล Student
- undo(): ถ้า INSERT ให้ลบออก ถ้า DELETE ให้ใส่กลับ ถูกต้อง
- เมนูครบ 6 ตัวเลือก (เพิ่ม/ลบ/แสดงไปหน้า/แสดงย้อนกลับ/Undo/ออก) วนด้วย do-while
- ใช้ malloc() และ free() ถูกต้องทุกครั้ง
- มี prototype declaration ทุกฟังก์ชันก่อน main()
- โปรแกรมต้องผ่านชุดทดสอบอัตโนมัติ: เพิ่มข้อมูล 5 คน และ Undo ต่อเนื่อง 2 ครั้ง โดยสถานะหลังแต่ละขั้นต้องถูกต้อง
- ไม่มี syntax error
